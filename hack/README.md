# Code Generation Scripts

This directory contains scripts for generating code using Kubernetes code generation tools.

## Scripts

### `generate-openapi.sh`

Generates OpenAPI schema definitions for types that have DeepCopy methods generated by `controller-gen`.

**Prerequisites:**
- `controller-gen` must have been run first to generate `zz_generated.deepcopy.go`
- `openapi-gen` will be automatically installed if not present

**Usage:**

```bash
# Via script
./hack/generate-openapi.sh

# Via Makefile
make generate.openapi
```

**What it does:**

1. Identifies types with DeepCopy methods from `models/components/zz_generated.deepcopy.go`
2. Temporarily adds `+k8s:openapi-gen=true` markers to those types
3. Runs `openapi-gen` to generate OpenAPI schema definitions
4. Removes the temporary markers
5. Runs `go mod tidy` to ensure dependencies are correct

**Output:**
- `models/components/zz_generated.openapi.go` - Contains OpenAPI schema definitions for all types with DeepCopy methods

**Dependencies Added:**
- `k8s.io/kube-openapi` - Required for OpenAPI generation and runtime

## Files

### `header-template.go.tmpl`

Template file containing the license header for generated code files.

## Integration with Existing Workflow

The OpenAPI generation is designed to work alongside the existing DeepCopy generation:

1. `make generate.deepcopy` - Generates DeepCopy methods for marked types
2. `make generate.openapi` - Generates OpenAPI schemas for the same types

Both generators work on the types in `models/components/` that have been marked for code generation.
